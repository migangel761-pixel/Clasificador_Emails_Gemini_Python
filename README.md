# Clasificador_Emails_Gemini_Python
Clasificador de Tickets/Emails:  Necesidad del Cliente: Tienen un gran volumen de emails de soporte y necesitan saber si son urgentes, preguntas de facturación, o reportes de bugs.  Tu Solución: Usar Python para leer los emails y la API de Gemini para clasificarlos y etiquetarlos automáticamente.
