# Clasificador_Tickets_Email
Clasificador de Tickets/Emails:  
Necesidad del Cliente: Tienen un gran volumen de emails de soporte y necesitan saber si son urgentes, preguntas de facturación, o reportes de bugs.
Tu Solución: Usar Python para leer los emails y la API de Gemini para clasificarlos y etiquetarlos automáticamente.

# 🚀 Clasificador Automático de Tickets de Soporte con Gemini API

## 🎯 El Problema Resuelto
Las empresas pierden tiempo clasificando manualmente los correos de soporte. 
Este proyecto automatiza esa tarea, asignando una **Categoría** y **Prioridad** a cada ticket en tiempo real.
